# AFN注册表

AFN为1字节二进制值，位于地址域之后、SEQ之前。

来源：S2009-PDF 4.3.4.2表5；S2009-DOC 4.3.4.2表5；REV13-DOC 4.3.4.2；EXT-V1.6 3.4。

| AFN | 标准业务 | 常见方向/响应 |
|---:|---|---|
| 00 | 确认/否认 | 双向响应；FIR=FIN=1、CON=0 |
| 01 | 复位 | 主站下行；终端以AFN=00确认/否认 |
| 02 | 链路接口检测 | 终端上行登录、退出、心跳；主站确认 |
| 03 | 中继站命令 | 下行命令/查询，上行同AFN应答 |
| 04 | 设置参数 | 下行设置；上行AFN=00确认/否认 |
| 05 | 控制命令 | 下行控制；上行AFN=00确认/否认 |
| 06 | 身份认证及密钥协商 | 双向同AFN；版本差异很大 |
| 07 | 备用 | 不应按标准业务解码 |
| 08 | 请求被级联终端主动上报 | 下行请求；上行可能返回原主动上报AFN，或否认 |
| 09 | 请求终端配置及信息 | 下行选择Fn，上行同AFN携带数据 |
| 0A | 查询参数 | 下行查询，上行同AFN返回与AFN=04相同参数结构 |
| 0B | 请求任务数据 | 下行请求；上行按任务类型以AFN=0C或0D应答 |
| 0C | 请求1类数据 | 下行通常仅数据单元标识，上行携带实时/状态数据 |
| 0D | 请求2类数据 | 下行带数据时标，上行携带历史数据 |
| 0E | 请求3类数据 | 下行事件指针范围，上行事件记录 |
| 0F | 文件传输 | 下行文件段，上行段标识/状态 |
| 10 | 数据转发 | 下行转发请求，上行转发结果 |
| 11～FF | 标准资料标为备用 | 不得用标准profile猜测 |
| FE | 仅厂站2.0扩展：协议扩展 | F4文件读取、F5 Shell命令 |

## Profile判定

- AFN=00～10且Fn<=248：可以先按标准公共层识别，再根据版本选择数据体schema。
- AFN=FE或Fn>248：必须有明确扩展profile；当前资料中只有 `station-2.0-v1.6` 提供部分定义。
- AFN=11～FD、FF：当前资料没有业务定义。

## AFN与链路层的关系

AFN属于应用层，C.FUNC属于链路层。二者不能互相替代。例如：

- C.FUNC=9表示链路测试服务，但应用业务通常通过AFN=02的登录/心跳表达。
- C.FUNC=10/11是链路访问等级，不等同于AFN=0C/0D。
- AFN=00是应用确认/否认，C.FUNC=0是链路认可；一帧可能同时具有相应的链路和应用语义。
