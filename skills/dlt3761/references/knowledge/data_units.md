# 数据单元与Schema选择

## 通用组织

应用层基本形态：

```text
AFN SEQ [DA1 DA2 DT1 DT2 DATA]... [AUX]
```

业务schema的唯一键至少是：

```text
(profile, direction, AFN, Fn, Pn-kind)
```

同一Fn的下行请求和上行响应经常不同；同一AFN/Fn在2009与修订资料中也可能不同。禁止建立只以Fn为键的全局解析表。

## 标准AFN的结构入口

| AFN | 下行/启动数据体 | 上行/响应数据体 | 证据 |
|---:|---|---|---|
| 00 | F1/F2无体；F3=`被确认AFN(1)+[DA/DT(4)+ERR(1)]...`；REV13 F4=`错误类型(1)+Data(16)` | 同类确认结构 | 5.1 |
| 01 | F1～F4无业务体，重要下行带PW | AFN=00确认/否认 | 5.2 |
| 02 | 通常由终端上行 | F1登录无体、F2退出无体；F3在REV13带终端时钟A.1(6)，2009未定义体 | 5.3 |
| 03 | F1控制1字节；F2～F4查询无体 | F1/F2状态1字节；F3十条切换记录；F4五个BIN16统计量 | 5.4 |
| 04 | 设置参数，各Fn专属体，重要下行带PW | AFN=00确认/否认 | 5.5 |
| 05 | 控制命令，各Fn专属体，重要下行通常带PW | AFN=00确认/否认 | 5.6 |
| 06 | 版本相关的认证、会话、证书、密钥体 | 同AFN响应；2009和REV13不兼容 | 5.7 |
| 08 | 明确使用DA=0、DT=0且无业务体 | 有数据时用被级联终端原AFN返回；无数据时否认 | 5.8 |
| 09 | 一组DA/DT选择器，通常无业务体 | 同AFN返回配置/能力数据 | 5.9 |
| 0A | 多数Fn只带选择器；F10/F11等查询带对象计数和序号 | 返回结构通常同AFN=04对应Fn | 5.10 |
| 0B | F1无体；F2带起始时刻A.15(5) | 任务1以0C响应，任务2以0D响应 | 5.11 |
| 0C | 通常只有DA/DT | 同AFN返回1类实时/状态数据 | 5.12 |
| 0D | 每个标识后带Td_c/Td_d/Td_m等时标 | 同AFN返回时标+历史数据 | 5.13 |
| 0E | F1/F2=`Pm(1)+Pn(1)` | `EC1+EC2+Pm+Pn+[ERC+Le+body]...` | 5.14 |
| 0F | F1文件标识、属性、指令、总段数、段偏移、段长和数据 | 2009/REV13应答结构有版本差异；REV13返回当前段标识4字节 | 5.15 |
| 10 | F1透明转发、F9直接抄读等 | 同Fn的转发结果结构 | 5.16 |

所有标准Fn名称和逐字段表均保留在完整文本源中：

- [revision_2012_13_compare_doc.txt](sources/revision_2012_13_compare_doc.txt)：修订差异，按AFN标题和`F<n>：`检索。

## 常用Fn注册摘要

### AFN=00

| Fn | 业务 |
|---:|---|
| F1 | 全部确认，P0，无数据体 |
| F2 | 全部否认，P0，无数据体 |
| F3 | 按数据单元标识逐项确认/否认，P0 |
| F4 | 仅REV13：硬件安全认证错误应答 |

ERR在2009附录D只定义0=正确、1=出错、2～255备用。

### AFN=01/02/03

- 01：F1硬件初始化、F2数据区初始化、F3参数及全体数据区初始化、F4保留主站通信参数的初始化。
- 02：F1登录、F2退出登录、F3心跳。
- 03：F1中继状态控制、F2状态查询、F3切换记录查询、F4运行统计查询。

### AFN=04/0A

AFN=0A复用AFN=04的Fn编号和响应结构。2009主要有效范围：

- F1～F8：上行通信、主站IP/电话、认证、组地址、终端IP和工作方式。
- F9～F16：事件、表计/交采、脉冲、状态量、模拟量、总加组、差动、VPN凭据。
- F17～F23：保安、功控、电控、费率和催费参数。
- F25～F31：测量点及集中抄表参数。
- F33～F39：抄表、通信模块、重点户、流量、级联及1/2类配置。
- F41～F49：功控/电控定值和告警。
- F57～F61：声音告警、保电、表异常、谐波、直流模拟量接入。
- F65～F68：定时上报任务及启停。
- F73～F76：电容器参数。
- F81～F83：直流模拟量变比、限值、冻结。
- REV13另定义F89逻辑地址、F90无线参数、F91地理位置和F150测量点状态等；这里的F150属于AFN=04，不能与AFN=05/F150“复位测量点参数变更标志”混淆。

### AFN=05

有效业务包括：F1跳闸、F2允许合闸；F9～F12功控投入；F15～F20电控/功控投入解除；F23～F29电控解除、保电、催费、通话、剔除、主动上报；F31对时、F32中文信息；F33～F39对应解除/禁止/连接控制；F41/F42电容器控制；F49～F53暂停、恢复、重抄、路由初始化和删表。

### AFN=06

- 2009：较早的F1身份认证请求、F2响应、F3取随机数、F4随机数响应。
- REV13：F11获取终端信息；F12会话初始化/恢复；F13会话协商；F14对称密钥更新；F15终端证书更新；F16 CA证书更新；F17内部认证；F18外部认证；F19状态切换；F20离线计数器；F21转加密授权。

二者不可自动兼容。

### AFN=09

F1终端版本；F2输入输出及通信端口；F3其他配置；F4参数配置能力；F5控制能力；F6一类数据能力；F7二类数据能力；F8事件能力；REV13增加F9远程通信模块版本、F10本地通信模块版本。

### AFN=0B/0E/0F/10

- 0B：F1请求定时上报1类任务；F2请求定时上报2类任务。
- 0E：F1重要事件；F2一般事件。
- 0F：F1文件传输方式1。
- 10：F1透明转发；F9直接抄读；2009 F10/F11为遥控转发而REV13取消；REV13增加F12批量表任务、F13查询执行状态。

## 1类、2类、3类数据

AFN=0C和0D的Fn数量很大，精确名称和逐字段schema以源文档表为准，不允许按相邻Fn类推。可按以下规则快速定位：

```text
rg -n "F<编号>：|F<编号>\t" references/knowledge/sources/*.txt
```

- 0C：终端状态、当前功率/电量、表计当前值、谐波、电容器、直流量等。
- 0D：日/月冻结、曲线、需量、谐波统计、分相电量和表计结算等；下行必须先按Fn确定Td类型。
- 0E：Fn只选择重要/一般事件，事件业务由记录内部ERC决定。

若源表没有给某Fn数据格式，输出“当前提供的协议资料中未找到该字段定义”，不能根据同组Fn复制schema。

## 厂站2.0 F819：主站连接参数

profile：`station-2.0-v1.6`；AFN=04设置、AFN=0A查询；Pn=P0；F819=`DT 04 66`。

### 设置下行/查询上行

```text
count:u8
repeat count times:
    channel_type:u8
    channel_index:u8
    protocol_type:u8
    heartbeat_type:u8
    terminal_address:bytes[6]
    timing_report_flags:u8
    # 以下仅文档明确为“以太网和无线类”
    work_mode:u8
    if work_mode == 0:               # 服务器
        link_type:u8                 # 0 TCP, 1 UDP
        listen_port:u16le
    elif work_mode == 1:             # 客户端
        link_type:u8                 # 0 TCP, 1 UDP
        heartbeat_period:u16le       # 秒
        master_port:u16le
        master_ip:bytes[4]           # 顺序为IP第1～4段
    else:
        error("未定义工作模式")
```

每组固定公共头11字节；以太网/无线服务器组共15字节，客户端组共21字节。整个数据体长度可由count和每组work_mode逐组验证，禁止把第一组模式套给全部组。

### 查询下行

DA/DT之后无业务数据体；终端返回所有类型通道的所有主站连接参数。这里仍应存在数据单元标识P0/F819。

### 字段枚举

```text
channel_type: 0 Ethernet, 1 wireless, 2 serial, 3 MODEM
heartbeat_type: 0 default, 1 376.1, 2 102, 3 Heilongjiang-102-wireless, 4 CSG-13
timing_report_flags: bit0 timing-enable, bit1 report-enable, bit2..7 reserved
```

协议类型表来自EXT-V1.6 3.1.1的F819说明，例如0=1376.1、1=376.1、7=山西102、30=面向对象、31=南网13、32=645、33=山西MQTT、34=网络安全、35=威胜102、36=山东102。中间未列出的编号不得猜测。

### terminal_address[6]

- 南网13：6字节；示例输入12345678，线上`12 00 00 78 56 34`。
- OOP/645：6字节低位在前；示例`78 56 34 12 00 00`。
- 376.1/1376.1/蒙西：有效4字节；行政码1234、地址5678编码`34 12 78 56 00 00`。
- 名称含102：有效2字节放中间；示例1234编码`00 00 34 12 00 00`。

这6字节是F819业务体中的终端地址，不是帧头5字节地址域A。

### F819未定义项

串口、MODEM类型的work_mode及后续体没有在EXT-V1.6中定义。遇到此类组时只能解析到公共11字节，并报告后续边界不确定。

### F817嵌入图补充规则

扩展文档的两张嵌入图补充了正文未抽出的标准档案字段约束，原图保存在 [图1](sources/extension_f817_standard_notes_1.png) 和 [图2](sources/extension_f817_standard_notes_2.png)：

- 本次表计/交采配置数量0～2040，配置序号1～2040。
- 所属测量点号0～2040；为0表示删除该配置序号的表计/交采档案。
- 速率及端口字节：D7..D5为速率码，1～7依次为600、1200、2400、4800、7200、9600、19200 bit/s，0为默认/无需设置；D4..D0为端口号1～31。
- 通信地址范围0～999999999999；采集器地址为0表示未经过采集器、直接接入终端。
- 费率数字节D3..D0为1～12，D7..D4备用。
- 有功示值位数字节：D3..D2编码0～3对应4～7位整数；D1..D0编码0～3对应1～4位小数；D7..D4备用。
- 用户分类字节高4位为大类0～15，低4位为小类0～15。
