# 控制域 C

```text
bit:   D7   D6   D5        D4        D3..D0
下行:  DIR  PRM  FCB       FCV       FUNC
上行:  DIR  PRM  ACD       保留      FUNC
```

## 位定义

| 位 | 名称 | 解释 |
|---|---|---|
| D7 | DIR | 0=主站发出的下行；1=终端发出的上行 |
| D6 | PRM | 1=来自启动站；0=来自从动站 |
| D5 下行 | FCB | 当FCV=1时为连续发送/确认或请求/响应服务的变化位 |
| D5 上行 | ACD | 1=终端有重要事件等待访问，AUX中应带EC；0=无等待访问的重要事件 |
| D4 下行 | FCV | 1=FCB有效；0=FCB无效 |
| D4 上行 | 保留 | 标准未赋业务意义，解析器只报告原始值；非0时标异常但不擅自解释 |
| D3..D0 | FUNC | 链路功能码，必须结合PRM解释 |

来源：S2009-PDF 4.3.3.2、图3、表2～3；REV13-DOC 4.3.3.2。

## FUNC（PRM=1）

| FUNC | 帧类型 | 服务功能 |
|---:|---|---|
| 1 | 发送/确认 | 复位命令 |
| 4 | 发送/无回答 | 用户数据 |
| 9 | 请求/响应 | 链路测试 |
| 10 | 请求/响应 | 请求1级数据，用于应用层CON=1的确认访问 |
| 11 | 请求/响应 | 请求2级数据 |
| 0、2～3、5～8、12～15 | — | 备用 |

## FUNC（PRM=0）

| FUNC | 帧类型 | 服务功能 |
|---:|---|---|
| 0 | 确认 | 认可 |
| 8 | 响应 | 用户数据 |
| 9 | 响应 | 否认：无所召唤的数据 |
| 11 | 响应 | 链路状态 |
| 1～7、10、12～15 | — | 备用 |

## FCB处理状态机

- 仅FCV=1时检查FCB。
- 启动站向同一从动站发送新的S2/S3服务时翻转FCB。
- 超时、接收错误或原帧重发时FCB不变。
- 从动站对相同FCB的重复请求重发已缓存响应，不重复执行业务；FCB变化才清除旧响应并处理新请求。
- 复位命令FCB=0；从动站接收复位命令后将保存的FCB置0。

不要把 `DIR` 与 `PRM` 合并：DIR表示物理业务方向，PRM表示本次链路服务的发起/从属关系。
