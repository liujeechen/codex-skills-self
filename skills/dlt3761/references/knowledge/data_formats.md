# 基础数据格式

## 通用编码规则

- 帧和多字节BIN：低位在前、低字节在前，除非具体数据单元明确另有规定。
- BCD：每个声明为BCD数字的半字节应为0～9；`A`～`F`只能在具体字段明确作为标志时出现。
- ASCII：按字串从左到右发送，最左字符先发；定长不足部分补`00`。来源：标准设置参数F3说明。
- BS：独立位组合，按字段表逐位解释，不能转成十进制后丢失未知/保留bit。
- `EE`：已定义数据项中的缺失字节；不是通用空值。

来源：S2009-PDF 4.2、附录A；S2009-DOC附录A；REV13-DOC附录A。

### A.2倍率

```text
G3 G2 G1 : multiplier
000 : 10^4
001 : 10^3
010 : 10^2
011 : 10^1
100 : 10^0
101 : 10^-1
110 : 10^-2
111 : 10^-3
```

修订文档表头有一处把 `G1`写成`G0`，正文及位定义使用G1；本库保留为排版差错记录，不改变三位倍率算法。

## 常用时间结构

| 名称 | 字节 | 内容 |
|---|---:|---|
| 终端日历时钟 | 6 | A.1：秒分时日星期/月年 |
| 通用5字节时刻 | 5 | A.15：分时日月年 |
| Tp发送时标 | 4 | A.16：秒分时日 |
| Td_c | 7 | 起始时间A.15(5)+冻结密度m(1)+点数n(1) |
| Td_d | 3 | A.20：日月年 |
| Td_m | 2 | A.21：月年 |

时间字段解析后应分别检查BCD合法性与日历范围；超范围时保留原始值并报告异常，不自动归一化。
